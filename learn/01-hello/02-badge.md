# Crachá

Escreva `badge`, que monta o texto do crachá de um congresso: o nome, o sobrenome e o ano entre parênteses.

```
badge("Ada", "Lovelace", 1815)  →  "Ada Lovelace (1815)"
badge("Grace", "Hopper", 1906)  →  "Grace Hopper (1906)"
```

Agora são três parâmetros, e um deles é um `Int` — um número inteiro. Encaixado num texto, ele vira texto sozinho.

## Dica

Dá para encaixar mais de um valor no mesmo texto: `"{a} e {b}"`.
