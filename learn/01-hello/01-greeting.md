# Saudação

O seu primeiro desafio. Escreva `greet`: ela recebe um nome e devolve uma saudação para ele.

```
greet("Ada")    →  "Olá, Ada!"
greet("Mundo")  →  "Olá, Mundo!"
```

Um desafio é uma `func`: os valores entram pelos parâmetros (`name: Str`) e um sai com `return`. O `: Str` depois dos parênteses diz o que ela devolve.

Aperte **▶ Run tests**: testes escondidos chamam a sua função com alguns nomes e dizem quais saíram certos.

## Dica

Monte a resposta do jeito que a lição montou as linhas dela: um texto com `{name}` dentro, `"…{name}…"`.
