# Greeting

Your first challenge. Write `greet`: it takes a name and returns a greeting for it.

```
greet("Ada")    →  "Hello, Ada!"
greet("World")  →  "Hello, World!"
```

A challenge is a `func`: values come in through its parameters (`name: Str`) and one goes back out with `return`. The `: Str` after the parentheses says what it returns.

Press **▶ Run tests**: hidden tests call your function with a few names and tell you which came out right.

## Hint

Build the answer the way the lesson built its lines: an interpolated string, `"…{name}…"`.
