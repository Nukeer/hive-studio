# Twice

Write `twice`, which takes a function and a number, and applies the function to the number two times over.

```
twice(addThree, 1)  →  7      (1 + 3 + 3)
twice(double, 5)    →  20     (5 × 2 × 2)
```

The parameter `f: func(Int): Int` is the function. Call it like any other: `f(x)`.

## Hint

What the first call answers is what the second call is given.
