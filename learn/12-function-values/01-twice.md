# Duas vezes

Escreva `twice`, que recebe uma função e um número, e aplica a função ao número duas vezes seguidas.

```
twice(addThree, 1)  →  7      (1 + 3 + 3)
twice(double, 5)    →  20     (5 × 2 × 2)
```

O parâmetro `f: func(Int): Int` é a função. Chame-a como qualquer outra: `f(x)`.

## Dica

O que a primeira chamada responde é o que a segunda recebe.
