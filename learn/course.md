# Aprender Hive

Um curso prático em quinze capítulos curtos, cada um sobre uma parte da linguagem. Um capítulo começa com uma **lição** — uma página para ler ao lado de um programa para rodar e mudar — e segue com **desafios**: uma função para você escrever, conferida por testes escondidos, cada uma um pouco mais funda que a anterior.

Não há projeto para montar. O seu código fica guardado enquanto você digita, e **Reset** sempre traz o original de volta.

Para a linguagem inteira de uma vez, faça o **tour oficial em hive-lang.run**.
