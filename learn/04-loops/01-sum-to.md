# Soma até N

Escreva `sumTo`: a soma de todos os números inteiros de 1 até `n`. Quando `n` é menor que 1 não há nada para somar, e a resposta é 0.

```
sumTo(3)   →  6      (1 + 2 + 3)
sumTo(10)  →  55
sumTo(0)   →  0
```

## Dica

Guarde um total `mut` e some o contador a ele em cada volta de um laço que conta.
