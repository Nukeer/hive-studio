# Learn Hive

A hands-on course in fifteen short chapters, each about one part of the language. A chapter opens with a **lesson** — a page to read beside a program to run and change — and goes on with **challenges**: a function for you to write, checked by hidden tests, each one a little deeper than the last.

There is no project to set up. Your code is kept as you type, and **Reset** always brings back the original.

For the whole language in one go, take the **official tour at hive-lang.run**.
