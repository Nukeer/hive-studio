# Rectangle

The code starts with a `Rect` type. Write two functions for it:

- `area`: the width times the height;
- `isSquare`: whether both sides are the same.

```
area(Rect(3, 4))      →  12
isSquare(Rect(3, 4))  →  false
isSquare(Rect(5, 5))  →  true
```

## Hint

Inside the functions, the sides are `r.width` and `r.height`.
