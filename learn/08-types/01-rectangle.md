# Retângulo

O código começa com um tipo `Rect`. Escreva duas funções para ele:

- `area`: a largura vezes a altura;
- `isSquare`: se os dois lados são iguais.

```
area(Rect(3, 4))      →  12
isSquare(Rect(3, 4))  →  false
isSquare(Rect(5, 5))  →  true
```

## Dica

Dentro das funções, os lados são `r.width` e `r.height`.
