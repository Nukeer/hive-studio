# Troca

Escreva o `proc` `swap`, que troca os valores de duas variáveis `mut Int`:

```
mut a := 1
mut b := 2
swap(a, b)
// agora a é 2 e b é 1
```

É o primeiro desafio que muda alguma coisa em vez de devolver, então é um `proc` e devolve `void`.

## Dica

Assim que você escreve `a = b`, o valor antigo de `a` se perdeu. Guarde-o com outro nome antes.
