# Soma

Escreva `sum`: todos os números de um vetor somados. Um vetor vazio soma 0.

```
sum([1, 2, 3])  →  6
sum([])         →  0
sum([-5, 5])    →  0
```

O parâmetro é um `Int[]`: um vetor de qualquer tamanho, então a função aceita todos.

## Dica

`for each` te entrega cada número sem índice nenhum.
