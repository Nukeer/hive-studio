# Sum

Write `sum`: all the numbers of a vector added together. An empty vector adds up to 0.

```
sum([1, 2, 3])  →  6
sum([])         →  0
sum([-5, 5])    →  0
```

The parameter is an `Int[]`: a vector of any length, so the function takes them all.

## Hint

`for each` hands you every number without indexing.
